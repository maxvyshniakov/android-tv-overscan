# Issue tracker

- Tracker: GitHub Issues in `maxvyshniakov/android-tv-overscan`.
- Language: English.
- Commands: `gh issue list`, `gh issue view <n>`, `gh issue comment <n>` (or T3 Code `list_issues` / `read_issue` / `comment_on_issue`).
- Reconciliation: label `integrated` after a green post-merge smoke on the integration branch; close only when the complete scope has shipped to `main`. Leave remaining hardware verification items as unchecked checklist items.
